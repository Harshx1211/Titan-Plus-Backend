# The Oracle - TITAN PLUS EDITION

Institutional-grade AI Trading Advisor for NSE F&O.

## Architecture
1. **Sentinel**: Data Truth & Triangulation.
2. **Strategist**: Regime Detection (Trending/Sideways/Uncertain).
3. **Risk Engine**: Meta-Buckets & Recovery Modes.
4. **Brain**: ML Filter with Rolling Feature Importance.
5. **Oracle**: Premium Next.js Command Center.

## Setup
1. `pip install -r requirements.txt`
2. `python api.py` (Starts the backend)
3. `cd dashboard && npm run dev` (Starts the UI)

## Philosophical Core
- **Quarantine over Profit**: Corrupted data is isolated.
- **Confirmation over Speed**: System waits for regimes to stabilize.
- **Accountability over Blind Faith**: User overrides are logged and analyzed.
